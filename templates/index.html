Ders 01 · Temeller

Django, web uygulamanın iskeletidir.

Django; URL'leri, Python kodunu, HTML şablonlarını ve veritabanını bir arada çalıştıran bir web çatısıdır. Tarayıcı bir istek gönderir; Django bu isteği doğru koda ulaştırıp bir yanıt üretir.

01 · URLİsteğin hangi adrese geldiğini bulur.
02 · ViewNe yapılacağına karar veren Python kodu.
03 · YanıtHTML sayfası veya başka bir sonuç.

Bu projede ana adres, ogrenme uygulamasına yönlenir; uygulamadaki view ise index.html şablonunu gösterir.

Ders 02 · İstek yönlendirme

URL, doğru view'ı bulur.

URL yapılandırmasında bir adresi view fonksiyonuna eşlersin. View, isteği alır ve bir HTTP yanıtı döndürür. Django'da bu eşleşme genellikle uygulamanın urls.py dosyasında tutulur.

ogrenme/url.py
from django.urls import path
from . import views

urlpatterns = [
		path("", views.index, name="index"),
]
ogrenme/views.py
from django.shortcuts import render

def index(request):
		return render(request, "index.html")

Tarayıcı ana adresi istediğinde Django index fonksiyonunu çalıştırır.

Ders 03 · HTML üretimi

View veriyi template'e taşır.

Şablon, HTML ile Python verisini birleştirir. View içinden sözlük biçiminde gönderdiğin değerleri çift süslü parantezle ekrana yazdırabilirsin.

ogrenme/views.py
def selamla(request):
		context = {"isim": "Django öğrencisi"}
		return render(request, "selam.html", context)
templates/selam.html
<h1>Merhaba, {{ isim }}!</h1>

Şablon etiketleriyle listeler üzerinde dönebilir veya koşullara göre içerik gösterebilirsin.

Ders 04 · Veri saklama

Model, verinin şeklini tanımlar.

Bir model Python sınıfıdır; alanları veritabanındaki sütunlara karşılık gelir. Modeli değiştirdikten sonra migration dosyalarını üretir ve veritabanına uygularsın.

ogrenme/models.py
from django.db import models

class Not(models.Model):
		baslik = models.CharField(max_length=120)
		olusturma = models.DateTimeField(auto_now_add=True)
Terminal
python manage.py makemigrations
python manage.py migrate

makemigrations değişiklik tarifini oluşturur; migrate bunu veritabanına uygular.
